1.1 Number Systems

Mathematics organizes numbers into sets. Each set extends the previous, adding new kinds of numbers.

Number system hierarchy — each set contains all sets inside it

1.2 Divisibility, Factors & Multiples

A number a is divisible by b if b divides a with no remainder. Written: b | a.

Divisibility Rules (shortcuts)
Div by 2: last digit is even (0,2,4,6,8)
Div by 3: sum of digits divisible by 3
Div by 4: last 2 digits divisible by 4
Div by 5: last digit is 0 or 5
Div by 6: divisible by both 2 and 3
Div by 9: sum of digits divisible by 9
Div by 10: last digit is 0
GCD and LCM
GCD(a,b) × LCM(a,b) = a × b

Euclidean Algorithm: GCD(a,b) = GCD(b, a mod b)
Keep applying until remainder = 0
Example — Find GCD(48, 18) and LCM(48, 18)
Using the Euclidean Algorithm:
1 GCD(48, 18): 48 = 2×18 + 12 → GCD(18,12)
2 GCD(18, 12): 18 = 1×12 + 6 → GCD(12,6)
3 GCD(12, 6): 12 = 2×6 + 0 → GCD = 6
4 LCM(48,18) = (48 × 18) / 6 = 864 / 6 = 144
1.3 Prime Numbers & Prime Factorization

A prime number is a natural number greater than 1 with no positive divisors other than 1 and itself.

Fundamental Theorem of Arithmetic
Every integer n > 1 can be written UNIQUELY as a product of primes:

n = p₁^a₁ × p₂^a₂ × p₃^a₃ × ... × pₖ^aₖ

Example: 360 = 2³ × 3² × 5¹
Example — Prime Factorization of 360
1 360 ÷ 2 = 180
2 180 ÷ 2 = 90
3 90 ÷ 2 = 45
4 45 ÷ 3 = 15
5 15 ÷ 3 = 5
6 5 ÷ 5 = 1 → Result: 360 = 2³ × 3² × 5
Factor tree for 360
Number of Divisors Formula
If n = p₁^a₁ × p₂^a₂ × ... × pₖ^aₖ, then:

Number of divisors τ(n) = (a₁+1)(a₂+1)...(aₖ+1)

Example: 360 = 2³×3²×5¹ → τ(360) = (3+1)(2+1)(1+1) = 4×3×2 = 24
1.4 Modular Arithmetic

Modular arithmetic is arithmetic on a "circle" of numbers. We say a ≡ b (mod n) if n divides (a − b).

Key Rules
(a + b) mod n = ((a mod n) + (b mod n)) mod n
(a × b) mod n = ((a mod n) × (b mod n)) mod n

Fermat's Little Theorem: aᵖ⁻¹ ≡ 1 (mod p) [p is prime, gcd(a,p)=1]
Example — Clock Arithmetic
What time is it 100 hours after 3:00?
1 We work mod 12 (12-hour clock)
2 (3 + 100) mod 12 = 103 mod 12
3 103 = 8×12 + 7 → remainder is 7
4 Answer: 7:00

2.1 Expressions & Polynomials

A polynomial is an expression of the form: aₙxⁿ + aₙ₋₁xⁿ⁻¹ + ... + a₁x + a₀

Factoring Identities (Must Memorize!)
Difference of squares: a² - b² = (a+b)(a-b)
Perfect square (sum): a² + 2ab + b² = (a+b)²
Perfect square (diff): a² - 2ab + b² = (a-b)²
Sum of cubes: a³ + b³ = (a+b)(a²-ab+b²)
Difference of cubes: a³ - b³ = (a-b)(a²+ab+b²)
FOIL: (a+b)(c+d) = ac+ad+bc+bd
Example — Factor completely: 2x³ - 8x
1 Factor out GCF: 2x(x² - 4)
2 Recognize difference of squares: 2x(x+2)(x-2)
✓ Answer: 2x(x+2)(x-2)
Binomial Theorem
(a + b)ⁿ = Σ C(n,k) × aⁿ⁻ᵏ × bᵏ for k=0 to n

Pascal's Triangle row n gives the coefficients:
n=0: 1
n=1: 1 1
n=2: 1 2 1
n=3: 1 3 3 1
n=4: 1 4 6 4 1

(a+b)³ = a³ + 3a²b + 3ab² + b³
2.2 Equations & Inequalities
Quadratic Formula
For ax² + bx + c = 0:

x = (-b ± √(b²-4ac)) / 2a

Discriminant Δ = b² - 4ac:
Δ > 0 → two distinct real roots
Δ = 0 → one repeated real root
Δ < 0 → two complex conjugate roots
Example — Solve: 2x² - 5x - 3 = 0
1 a=2, b=-5, c=-3
2 Δ = (-5)² - 4(2)(-3) = 25 + 24 = 49
3 x = (5 ± √49) / 4 = (5 ± 7) / 4
4 x₁ = (5+7)/4 = 3, x₂ = (5-7)/4 = -½
✓ Roots: x = 3 and x = -1/2
Vieta's Formulas (for x² + bx + c = 0 with roots r₁, r₂)
Sum of roots: r₁ + r₂ = -b/a
Product of roots: r₁ × r₂ = c/a
Absolute Value Equations
|x| = a → x = a or x = -a
|x| < a → -a < x < a
|x| > a → x < -a or x > a
2.3 Systems of Equations
Cramer's Rule (2×2 system)
For: a₁x + b₁y = c₁
a₂x + b₂y = c₂

D = |a₁ b₁| = a₁b₂ - a₂b₁
|a₂ b₂|

x = Dₓ/D, y = D_y/D
where Dₓ = c₁b₂ - c₂b₁, D_y = a₁c₂ - a₂c₁
Example — Solve the system: 3x + 2y = 8 and x - y = 1
1 Substitution: x = 1 + y
2 3(1+y) + 2y = 8 → 3 + 3y + 2y = 8 → 5y = 5 → y = 1
3 x = 1 + 1 = 2
✓ Solution: x = 2, y = 1
2.4 Functions & Relations

A function maps each input (domain) to exactly one output (range). Written f: X → Y.

Key Function Operations
Composition: (f∘g)(x) = f(g(x))
Inverse: f⁻¹(f(x)) = x [only if f is bijective]
Even function: f(-x) = f(x) [symmetric about y-axis]
Odd function: f(-x) = -f(x) [symmetric about origin]
A function maps each element of the domain to exactly one element of the range

2.6 Sequences & Series
Arithmetic Sequence
aₙ = a₁ + (n-1)d

Sₙ = n/2 × (a₁ + aₙ)
Sₙ = n/2 × (2a₁ + (n-1)d)

d = common difference

aₙ = a₁ × rⁿ⁻¹

2.8 Complex Numbers
Complex Number Forms
Rectangular: z = a + bi (a=real, b=imaginary)
Polar: z = r(cosθ + i sinθ) = r·e^(iθ)
Modulus: |z| = r = √(a² + b²)
Argument: θ = arctan(b/a)

Calculus
The mathematics of continuous change — limits, derivatives, integrals, and infinite series.
6.1 Limits & Continuity

A limit describes the value a function approaches as input approaches some value.

Limit Laws
lim[f(x) ± g(x)] = lim f(x) ± lim g(x)
lim[f(x)·g(x)] = lim f(x) · lim g(x)
lim[f(x)/g(x)] = lim f(x) / lim g(x) [if denom ≠ 0]
lim[f(x)]ⁿ = [lim f(x)]ⁿ

Special limits:
lim(x→0) sin(x)/x = 1
lim(x→0) (1-cos x)/x = 0
lim(x→∞) (1 + 1/x)ˣ = e
lim(x→0) (1 + x)^(1/x) = e

L'Hôpital's Rule (0/0 or ∞/∞ form):
lim f(x)/g(x) = lim f'(x)/g'(x)
Example — Evaluate: lim(x→2) (x²-4)/(x-2)
1 Direct substitution gives 0/0 (indeterminate)
2 Factor: (x²-4)/(x-2) = (x+2)(x-2)/(x-2) = x+2
3 lim(x→2) (x+2) = 2+2 = 4
6.2 Derivatives

The derivative measures the instantaneous rate of change of a function.

Definition of the Derivative
f'(x) = lim(h→0) [f(x+h) - f(x)] / h

Notation: f'(x), dy/dx, Df(x), ẏ (for time derivatives)
Differentiation Rules (Must Memorize!)
Constant: d/dx [c] = 0
Power: d/dx [xⁿ] = nxⁿ⁻¹
Constant mult: d/dx [cf] = c·f'
Sum/Diff: d/dx [f±g] = f'±g'
Product: d/dx [fg] = f'g + fg'
Quotient: d/dx [f/g] = (f'g - fg')/g²
Chain: d/dx [f(g(x))] = f'(g(x))·g'(x)

Exponentials/Logs:
d/dx [eˣ] = eˣ
d/dx [aˣ] = aˣ ln(a)
d/dx [ln x] = 1/x
d/dx [logₐx] = 1/(x·ln a)

Trig functions:
d/dx [sin x] = cos x
d/dx [cos x] = -sin x
d/dx [tan x] = sec²x
d/dx [sec x] = sec x tan x
d/dx [csc x] = -csc x cot x
d/dx [cot x] = -csc²x
Example — Differentiate: f(x) = x³·sin(x)
1 Use Product Rule: [uv]' = u'v + uv'
2 u = x³, u' = 3x²
3 v = sin x, v' = cos x
4 f'(x) = 3x²·sin(x) + x³·cos(x)
✓ Answer: f'(x) = x²(3sin x + x cos x)
6.3 Applications of Derivatives
Critical Points & Optimization
Critical points: where f'(x) = 0 or f'(x) undefined

First Derivative Test:
f' changes + → -: local maximum
f' changes - → +: local minimum

Second Derivative Test:
f''(c) < 0 → local max at x=c
f''(c) > 0 → local min at x=c
f''(c) = 0 → inconclusive

Inflection point: where f''(x) changes sign

Mean Value Theorem:
If f continuous on [a,b] and differentiable on (a,b),
then ∃ c ∈ (a,b) such that f'(c) = (f(b)-f(a))/(b-a)
6.4 Integration
Basic Integration Rules
∫ xⁿ dx = xⁿ⁺¹/(n+1) + C (n ≠ -1)
∫ x⁻¹ dx = ln|x| + C
∫ eˣ dx = eˣ + C
∫ aˣ dx = aˣ/ln(a) + C
∫ sin x dx = -cos x + C
∫ cos x dx = sin x + C
∫ sec²x dx = tan x + C
∫ csc²x dx = -cot x + C
∫ 1/√(1-x²) dx = arcsin(x) + C
∫ 1/(1+x²) dx = arctan(x) + C
Fundamental Theorem of Calculus
Part 1: d/dx [∫(a to x) f(t) dt] = f(x)

Part 2: ∫(a to b) f(x) dx = F(b) - F(a)
where F is any antiderivative of f

Integration by substitution (u-sub):
Let u = g(x), then du = g'(x)dx
∫ f(g(x))g'(x) dx = ∫ f(u) du

Integration by parts:
∫ u dv = uv - ∫ v du
LIATE: Logs, Inverse trig, Algebraic, Trig, Exponential
Example — Compute ∫(0 to 2) x²dx
1 Find antiderivative: F(x) = x³/3
2 Apply FTC Part 2: F(2) - F(0) = 8/3 - 0 = 8/3
6.5 Taylor & Maclaurin Series
Taylor Series at x = a
f(x) = Σ f⁽ⁿ⁾(a)/n! × (x-a)ⁿ [n=0 to ∞]

Common Maclaurin Series (a=0):
eˣ = 1 + x + x²/2! + x³/3! + ... = Σ xⁿ/n!
sin x = x - x³/3! + x⁵/5! - ... = Σ (-1)ⁿx^(2n+1)/(2n+1)!
cos x = 1 - x²/2! + x⁴/4! - ... = Σ (-1)ⁿx^(2n)/(2n)!
1/(1-x)= 1 + x + x² + x³ + ... [|x|<1]
ln(1+x)= x - x²/2 + x³/3 - ... [|x|≤1, x≠-1]

7.1 Vector Spaces & Subspaces
Key Concepts

Linear independence: c₁v₁+...+cₖvₖ=0 ⟹ all cᵢ=0

Rank-Nullity Theorem:
rank(A) + nullity(A) = number of columns of A
7.2 Eigenvalues & Eigenvectors
Finding Eigenvalues and Eigenvectors
Definition: Av = λv (v ≠ 0)

Step 1: Find eigenvalues λ by solving det(A - λI) = 0
This is the characteristic equation

Step 2: For each λ, find eigenvectors by solving:
(A - λI)v = 0

Trace: tr(A) = sum of eigenvalues
det(A) = product of eigenvalues

Diagonalization: A = PDP⁻¹
D = diagonal matrix of eigenvalues
P = matrix of eigenvectors (as columns)
Example — Find eigenvalues of A = [[3,1],[1,3]]
1 det(A - λI) = 0: det[[3-λ, 1],[1, 3-λ]] = 0
2 (3-λ)² - 1 = 0 → 9 - 6λ + λ² - 1 = 0 → λ² - 6λ + 8 = 0
3 (λ-4)(λ-2) = 0 → λ₁ = 4, λ₂ = 2
7.3 Inner Product Spaces & Orthogonality
Gram-Schmidt Process
Given basis {v₁, v₂, ..., vₙ}, orthonormal basis {e₁,...,eₙ}:

u₁ = v₁
u₂ = v₂ - (v₂·u₁/u₁·u₁)u₁
u₃ = v₃ - (v₃·u₁/u₁·u₁)u₁ - (v₃·u₂/u₂·u₂)u₂
eₖ = uₖ/|uₖ| (normalize)

Projection of v onto u:
proj_u(v) = (v·u/u·u)·u

8.1 First-Order ODEs
Types of First-Order ODEs
Separable: dy/dx = f(x)g(y)
Solution: ∫ dy/g(y) = ∫ f(x) dx

Linear: dy/dx + P(x)y = Q(x)
Integrating factor: μ(x) = e^(∫P dx)
Solution: y = (1/μ)∫ μQ dx

Exact: M dx + N dy = 0 where ∂M/∂y = ∂N/∂x
Solution: F(x,y) = C where ∂F/∂x=M, ∂F/∂y=N
Example — Solve: dy/dx = 2xy (separable)
1 Separate: dy/y = 2x dx
2 Integrate both sides: ln|y| = x² + C
3 Exponentiate: y = Ae^(x²) where A = ±e^C
8.2 Second-Order Linear ODEs
ay'' + by' + cy = 0 — Characteristic Equation
ar² + br + c = 0

Case 1 (Δ > 0): two distinct real roots r₁, r₂
y = C₁e^(r₁x) + C₂e^(r₂x)

Case 2 (Δ = 0): repeated root r
y = (C₁ + C₂x)e^(rx)

Case 3 (Δ < 0): complex roots r = α ± βi
y = e^(αx)[C₁cos(βx) + C₂sin(βx)]

For non-homogeneous: use undetermined coefficients
or variation of parameters
Example — Solve: y'' - 5y' + 6y = 0
1 Characteristic equation: r² - 5r + 6 = 0
2 Factor: (r-2)(r-3) = 0 → r₁=2, r₂=3
3 General solution: y = C₁e^(2x) + C₂e^(3x)

The mathematics of uncertainty, random events, and drawing conclusions from data.
9.1 Combinatorics & Counting
Counting Principles
Multiplication rule: n₁ × n₂ × ... ways for sequential choices
Addition rule: n₁ + n₂ ways for mutually exclusive choices

Permutations (ordered): P(n,r) = n!/(n-r)!
Combinations (unordered): C(n,r) = n! / (r!(n-r)!)

Permutations with repetition: nʳ
Permutations with identical items: n! / (n₁! n₂! ... nₖ!)

Pascal's identity: C(n,r) = C(n-1,r-1) + C(n-1,r)
Example — A class of 30 students. How many ways to pick a committee of 5?
1 Order doesn't matter → Combination
2 C(30,5) = 30! / (5! × 25!) = (30×29×28×27×26)/(5×4×3×2×1)
3 = 142506 / 1 → 142,506 ways
9.2 Probability Rules
Core Probability Formulas
P(A) ∈ [0,1], P(sample space) = 1

Complement: P(Aᶜ) = 1 - P(A)
Union: P(A∪B) = P(A) + P(B) - P(A∩B)
Mutually excl.: P(A∪B) = P(A) + P(B)
Independent: P(A∩B) = P(A)·P(B)
Conditional: P(A|B) = P(A∩B)/P(B)

Bayes' Theorem:
P(A|B) = P(B|A)·P(A) / P(B)

Total Probability:
P(B) = Σ P(B|Aᵢ)·P(Aᵢ)
Example — Bayes' Theorem: Medical Test
A disease affects 1% of population. Test is 99% sensitive and 95% specific. If you test positive, what's the probability you have the disease?
1 P(Disease) = 0.01, P(Positive|Disease) = 0.99, P(Positive|No Disease) = 0.05
2 P(Positive) = 0.99×0.01 + 0.05×0.99 = 0.0099 + 0.0495 = 0.0594
3 P(Disease|Positive) = (0.99×0.01)/0.0594 ≈ 16.7%
! Even with a positive test, probability is only ~17% — base rate matters!

9.4 Descriptive Statistics
Key Statistical Measures
Mean: x̄ = (Σxᵢ)/n
Median: middle value (sorted data)
Mode: most frequent value

Range: max - min
Variance: s² = Σ(xᵢ - x̄)² / (n-1) [sample]
σ² = Σ(xᵢ - μ)² / n [population]
Std Dev: s = √(s²)

IQR: Q3 - Q1 (interquartile range)
z-score: z = (x - μ) / σ

Pearson r = Σ[(xᵢ-x̄)(yᵢ-ȳ)] / [(n-1)sₓsᵧ]
r ∈ [-1, 1], r=0 means no linear correlation
9.5 Hypothesis Testing
Steps for Hypothesis Test
1. State H₀ (null) and H₁ (alternative)
2. Choose significance level α (typically 0.05)
3. Calculate test statistic:

z-test: z = (x̄ - μ₀) / (σ/√n)
t-test: t = (x̄ - μ₀) / (s/√n) [df = n-1]
χ²-test: χ² = Σ (O-E)²/E

4. Find p-value or critical region
5. Decision: reject H₀ if p-value < α

Confidence interval for μ:
x̄ ± z*(σ/√n) [z* = 1.96 for 95% CI]
x̄ ± t*(s/√n) [use t-table for df]
